Install ty just to have a langserver to explore:
1. `python3 -m venv env`
2. `. env/bin/activate`
3. `pip install ty`

how to install simple_lsp_client:
1. At top of vscodium, type `>ext`, click "Extensions: Show Enabled Extensions"
2. Drag .vsix file from simple_lsp_client releases to vscodium extensions sidebar on left side
3. Right-click "Simple Lsp Client", go to settings
4. Copy my_simple_lsp_client_config.json there
